## Huffman codes

My simple, naive implementation of Huffman coding, made for educational purposes.\
Run `make run` to try it.

`huffman_encode` builds a canonical Huffman code and encodes the bytes.\
`huffman_decode` decodes the encoded bytes using the provided code lengths.\
`main` reads its own executable, encodes it, decodes it and writes the result to the `main2` file.
